## 技术栈

- React 19 + TypeScript + Vite 7
- Tailwind CSS 3（自定义森林绿主题变量，见 `src/index.css`）
- 坦克大战：原生 Canvas 2D，无第三方游戏引擎

## 本地运行

```bash
npm install       # 安装依赖
npm run dev       # 开发预览：http://localhost:3000（简历），/tank.html 为游戏页
npm run build     # 构建静态产物到 dist/，可直接部署
```

## 目录结构

```
├── index.html            # 简历页入口
```

## 设计说明

### 必做题 · 简历

- **配色**：森林墨绿 + 米色纸面的单色体系，明暗双主题均保证对比度；
- **排版**：衬线大标题 + 宽字距英文眉题的编辑式设计，首屏宣言跨行断句；
- **交互**：滚动进入视口的错落淡入、高考数据滚动计数、导航毛玻璃、明暗主题切换并记忆选择；
- **响应式**：移动端自动切换为单栏布局。

### 附加题 · 坦克大战

- **身份标识**：地图中央区域砖墙摆放为本人姓名拼音首字母 **CBH**（见 `src/tank/main.ts` 中 `buildMap` 函数与字母点阵表）；
- **底图素材**：游戏底图使用「浪尖儿大学生社区」（浪尖箐英）认证页截图（`public/tank-bg.jpg`），叠加半透明遮罩保证可读性；
- **玩法规则**：方向键 / WASD 移动，空格开火；敌方坦克共 10 辆（场上至多 3 辆），全部消灭获胜；我方被击中 3 次失败；红砖可被炮弹击碎，可借助「CBH」砖墙作掩体；出生有 2 秒无敌保护。
