# 坦克大战 · CBH

RST 竞赛训练营附加题作品 —— **陈博皓**（杭州师范大学 · 汉语国际教育 2026 级）

原生 Canvas 2D 实现的坦克大战小游戏，不依赖任何游戏引擎。

## 运行

```bash
npm install
npm run dev       # 开发预览
npm run build     # 构建静态产物到 dist/，可直接部署到 GitHub Pages / Vercel / Netlify
```

## 玩法

- `↑ ↓ ← →` 或 `W A S D` 移动，`空格` 发射炮弹
- 敌方坦克共 10 辆（场上同时至多 3 辆），全部消灭即获胜
- 我方被击中 3 次失败；每次重生有 2 秒无敌保护
- 红砖可被炮弹击碎——可以打掉砖墙开路，也可以留作掩体

## 赛题加分点对应

1. **身份标识**：地图中央区域的砖墙摆放为本人姓名拼音首字母 **CBH**，
   见 `src/main.ts` 的 `LETTERS` 字母点阵表与 `buildMap()` 函数；
2. **底图素材**：游戏底图使用「浪尖儿大学生社区」（浪尖箐英）认证页截图
   （`public/tank-bg.jpg`），叠加半透明暗色遮罩保证坦克与砖墙清晰可读；
   加载失败时自动回退为纯色场地；
3. **基本可玩性**：移动 / 开火 / 敌方 AI（随机巡逻 + 概率朝向玩家）/ 砖墙破坏 /
   生命与胜负判定 / 结算遮罩与重开。
